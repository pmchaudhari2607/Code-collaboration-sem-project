# Backend

## Running this project
The backend must be running before the frontend will work — if you see ERR_CONNECTION_REFUSED in the browser console, the backend is not running; start it first.

1. Start the backend:
```bash
cd backend
node server.js
```

2. Serve the frontend:
Serve the `frontend/` folder using a static server like VS Code Live Server on `http://127.0.0.1:5500`.
